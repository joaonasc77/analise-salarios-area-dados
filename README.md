# Resumo
Este projeto realiza uma **análise exploratória de dados salariais na área de Dados**, utilizando Python e bibliotecas amplamente usadas no mercado. Além da análise em notebook, o projeto também pode ser executado como um **dashboard interativo com Streamlit**.

O objetivo é compreender como fatores como **cargo, senioridade, tipo de contrato, modelo de trabalho (presencial, híbrido ou remoto)** e **tamanho da empresa** se relacionam com os salários na área de Dados.

---

## 🎯 Objetivos do Projeto

* Explorar e compreender a estrutura do conjunto de dados
* Realizar limpeza, tradução e padronização das variáveis
* Analisar a distribuição de salários na área de Dados
* Comparar salários por cargo, senioridade e modelo de trabalho
* Apresentar os resultados de forma clara por meio de visualizações em uma Dashboard

---

## 🛠️ Tecnologias Utilizadas

* **Python**
* **Pandas** – manipulação e análise de dados
* **Plotly** – visualização de dados interativa
* **Streamlit** – criação do dashboard
* **Matplotlib** - criação de gráficos estáticos e personalização de visualizações
* **Seaborn** - geração de visualizações estatísticas com foco em análise exploratória
* **Numpy** - operações matemáticas e manipulação eficiente de arrays numéricos

---

## 📌 Principais Insights de Dados

* Profissionais em níveis mais altos de senioridade apresentam salários significativamente maiores, reforçando o impacto da experiência na remuneração.
* O modelo de trabalho remoto aparece com forte representatividade no conjunto de dados, indicando uma consolidação desse formato na área de Dados.
* Cargos técnicos mais especializados tendem a apresentar salários médios mais elevados em comparação a posições mais generalistas.
* Empresas de médio e grande porte concentram a maior parte das oportunidades e, em média, oferecem melhores salários.
* O tipo de contrato tempo integral é predominante, refletindo o perfil mais estável das vagas analisadas.
